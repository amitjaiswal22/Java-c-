This repository contains clean, modular console applications demonstrating core Object-Oriented Programming (OOP), Data Structures & Algorithms, and Standard Template Library (STL) usage in Java and C++.

## 1. Movie Ticket Booking System (Java)
A console-based ticket reservation backend system built using core Java OOP principles and collections.

### Features:
- **Dynamic Seat Mapping:** Real-time visual tracking of available (`.`) and booked (`X`) seats.
- **Robust Exception Handling:** Prevents double-booking conflicts and invalid boundary entries.
- **Object-Oriented Design:** Clear separation of concerns using `Movie`, `Theater`, and main execution classes.

### How to Run:
```bash
javac MovieBookingSystem.java
java MovieBookingSystem
